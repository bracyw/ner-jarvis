# ner-jarvis

The **NER software onboarding workspace**. The `ner-jarvis` installer clones this
repo into a directory you choose and opens Claude Code here, with the NER skills and
data sources already set up.

Everything you need is in the installed skills (which resolve people, repos, and
docs live) — see [`CLAUDE.md`](CLAUDE.md). This repo stays intentionally minimal.

Hit a doc that misled you? Tell Claude, or run `ner-jarvis stale add`. Reports stay
local until you `ner-jarvis stale export` and share them.
